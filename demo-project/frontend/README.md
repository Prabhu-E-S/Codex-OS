# TaskForge Frontend

React 18 + TypeScript + Vite modern client application for TaskForge.

## Features
- Dynamic Dashboard with project & task metrics, priority & status breakdown
- Project Management (Create, List, Details, Progress tracking)
- Task Management (Create, Edit, Delete, Filter by status, priority, and project)
- Interactive Search across titles and descriptions
- Task Details Modal with real-time comment threads
- Overdue task visual alerts and status badges
- Responsive layout with dark modern aesthetic

## Development

```bash
# Install dependencies
npm install

# Start Vite dev server with backend proxy
npm run dev
```

## Production Build

```bash
npm run build
```
